# The automated automation

**Pattern 004 · Category: devops**

**Created: 2026-10-22T17:05:21Z**

> *“Manual intervention is a bug. Even when fixing it becomes your full-time job.”*

## Problem

A repetitive task takes three clicks every few weeks.

## Solution

Write a script, schedule it, monitor the scheduler, add automatic recovery, and build an orchestrator to coordinate the monitors. Automate the maintenance of the orchestrator as a final touch.

## Benefits

- Humans are removed from the happy path.
- Every component gets its own dashboard.
- A simple task becomes a formidable portfolio project.

## Success metric

Keeping the automation running takes longer than doing the task manually.

## The ultimate achievement

A manual checklist is introduced to make sure all the automations are still alive.
