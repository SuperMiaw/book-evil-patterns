# Too many choices

**Pattern 006 · Category: process**

**Created: 2026-10-22T17:05:21Z**

> *“Why decide when you can compare one more alternative?”*

## Problem

You need a name, a folder layout, and a static-site generator.

## Solution

Evaluate every possible tool and convention. Just before committing to one, discover an exciting alternative and restart the comparison.

## Benefits

- No option is prematurely dismissed.
- Decision documents grow organically.
- You cannot choose the wrong implementation if you choose none.

## Success metric

More hours are spent picking tools than using them.

## The ultimate achievement

The project is postponed because starting it became too complicated.
